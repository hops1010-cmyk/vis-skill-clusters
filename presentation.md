# Skill Clusters — Presentation

## Overview

This presentation introduces the Vistamations skill-cluster catalog: a public-facing map of 186 skills across 73 category directories, grouped into twelve primary clusters. It is Part 2 of a four-run, 4,000-word package (target: 1,000 words here).

## Why clusters

Skills are numerous and overlap. A flat list of 186 entries is unusable for navigation. Clusters group skills by the kind of work they support, so a reader can find the right tool without memorising every name. Each cluster has one primary home per skill, with secondary tags (security, research, media, deployment) for cross-cutting concerns.

## The twelve clusters

1. **Hermes and agent orchestration** — agent use, skill authoring, delegation.
2. **Cloudflare, edge and deployment** — Workers, durable state, Turnstile.
3. **Tower and Vistamations operations** — service discovery, project protocol, file placement.
4. **Frontend and web UI** — codebase, design references, animation, performance.
5. **Media and creative production** — interactive graphics, math animation, ASCII video, music.
6. **Productivity and documents** — document, workspace, email workflows.
7. **Software engineering** — Git hygiene, debugging, TDD, code review.
8. **Research and knowledge** — papers, citations, knowledge bases.
9. **Store and commerce** — product content, delivery, commerce data flow.
10. **System architecture** — identity, diagrams, gates, service mesh.
11. **Base model** — reusable Tower interface and wizard foundations.
12. **GitHub document repo** — repository-backed publication workflow.

## How to use

Browse `index.html` for the cluster table. Read `report.md` for inventory basis and taxonomy. Use skill names as examples, not endorsements. Treat counts as provisional until the deduplication pass.
