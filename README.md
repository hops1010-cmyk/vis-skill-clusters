# Vistamations Skill Clusters

A public catalog mapping the skills used across Tower and Vistamations work into twelve navigable clusters. The catalog is intentionally concise: names and one-line descriptions only, with no internal procedures exposed.

## What is here

- **index.html** — the cluster table (186 skills across 73 category directories).
- **report.md** — inventory basis, taxonomy decisions, validation, and stability notes.
- **presentation.md** — overview, cluster list, usage, status.
- **summary.md** — package wrap-up and word-count reconciliation.

## The twelve clusters

Hermes and agent orchestration; Cloudflare, edge and deployment; Tower and Vistamations operations; Frontend and web UI; Media and creative production; Productivity and documents; Software engineering; Research and knowledge; Store and commerce; System architecture; Base model; and GitHub document repo.

## How to use

Browse index.html for the table. Read report.md for the inventory basis and caveats. Skill names are examples, not endorsements. Counts are provisional until a deduplication pass reconciles canonical sources and profile availability. Secondary tags such as security, research, media, and deployment allow cross-cutting discovery without duplicating rows.

## Publication boundary

This repository is public. Names and one-line descriptions only. No local paths, credentials, private service addresses, or internal skill instructions. A public-content review gates any expansion beyond names and descriptions.
